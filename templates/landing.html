ADVANCED CLIPPING TOOLS

FFmpeg splitting, Whisper transcription, NLP hook detection, multi-LLM analysis, 9:16 vertical fit with blurred backgrounds, and a persistent video library.

Clipper is a free, self-hosted tool. You'll need Python, FFmpeg, and optionally API keys for Groq, Gemini, or NVIDIA for enhanced LLM-based analysis. The core NLP engine works without any API keys.

Yes. Clipper supports MP4, AVI, MOV, MKV, WebM, FLV, WMV, and M4V. You can also paste YouTube URLs and the built-in downloader will fetch the video automatically using yt-dlp.

Clipper uses OpenAI Whisper for transcription, then runs NLP-based hook detection (question hooks, emotional triggers, story openers, controversy markers, and more) to score and rank clip-worthy segments. Optionally, LLMs can provide a second-pass analysis.

The core pipeline (transcription + NLP analysis + splitting) runs entirely locally with no internet required. LLM fallback analysis needs API access, but it's optional.

Upload your best long-form videos alongside the short clips you made from them. Clipper extracts patterns (preferred durations, hook types, pacing) and personalizes all future analysis to match your unique editing style.
